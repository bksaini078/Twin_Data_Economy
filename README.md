# Twinlytics - A Human-Owned Behavioural Data Economy

Interactive HTML pitch presentation detailing **Twinlytics**: a research-led platform where individuals build AI-powered digital twins from their behavioural data and participate directly in the economic value generated.

## Overview

- **Interactive Presentation Deck:** `twin_economy_pitch.html`
- **Core Features:**
  - Interactive Canvas Data Pipeline & Twin Architecture Animation
  - 5-Year Strategic Multi-Phase Roadmap (Phase View & Matrix View)
  - Consented Human Signal & Market Growth Trajectory Charts
  - Quick Jump Slide Grid Overview (`G` key or Topbar button)
  - Fullscreen Presentation Mode & Dark/Light Theme Support
  - Responsive, high-legibility layout

## Author & Citation

- **Author:** Bhupender Kumar Saini (Fraunhofer IAO, Stuttgart)
- **Scientific Validation:** Core methodology accepted at CHI 2026 and UMAP 2026.
